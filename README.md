# Ambiente VR: ADTC Quixadá (Metaverso)

**Autor:** Francisco Josias da Silva Batista <br>
**Plataforma Alvo:** Android (Meta Quest) <br>
**Motor Gráfico:** Unity 6 LTS (6000.3.13f1) com Meta XR SDK

## Apresentando o Seu Projeto
Este repositório contém o projeto final de nível avançado focado no desenvolvimento de ambientes para o Metaverso. A aplicação é uma experiência em Realidade Virtual (VR) que recria o interior do salão da Igreja Assembleia de Deus Templo Central (ADTC), localizada no centro de Quixadá - CE. O ambiente 3D contempla a área de assentos, o púlpito e o telão de projeção, permitindo navegação fluida em primeira pessoa pelo PC.

## Contexto e Objetivos
O ambiente foi construído sob o contexto de **comunicação e congregação**. O objetivo principal no Metaverso é demonstrar como espaços físicos de reunião comunitária e espiritualidade podem ser virtualizados. Isso abre portas para acessibilidade, permitindo que indivíduos participem de palestras, cultos ou eventos imersivos remotamente, quebrando barreiras geográficas.
